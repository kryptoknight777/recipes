# recipes

[AutoPkg](https://github.com/autopkg/autopkg) recipes for macOS software packaging and Munki import.

```
autopkg repo-add https://github.com/kryptoknight777/recipes.git
```

## Available recipes

| App | Recipes |
| --- | --- |
| [Docker Desktop](DockerDesktop) (Apple Silicon) | `.download`, `.install`, `.pkg`, `.munki` |
| [Firefox](Firefox) | `.download`, `.install`, `.pkg`, `.munki` |
